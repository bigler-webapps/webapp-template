# Frontend (Vite)

## Commands

- `pnpm dev`: starts local development server (default `http://localhost:5173`)
- `pnpm build`: builds production assets into `build/`
- `pnpm preview`: serves the production build locally
- `pnpm test`: placeholder (no frontend tests configured)

## Notes

- Entry HTML is `frontend/index.html`.
- Static public files are served from `frontend/public/`.
